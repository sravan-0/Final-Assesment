# Feedback Admin Panel

A responsive MERN application for reviewing course feedback and managing submitted ratings.

## Requirements

- Node.js 18 or newer
- A MongoDB Atlas cluster and database user

## Configure the backend

1. Open `backend/.env`.
2. Replace the sample `MONGODB_URI` value with your MongoDB Atlas connection string. Use a test database and a temporary exam-only database user.
3. Keep the database user's password URL-encoded if it contains special characters.

## Run the project

Open two terminals from the project root.

Terminal 1:

```bash
npm install --prefix backend
npm start --prefix backend
```

Terminal 2:

```bash
npm install --prefix frontend
npm run dev --prefix frontend
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

The backend runs on port 5000 by default. The frontend uses `/api` requests through the Vite development proxy.

## API routes

- `GET /api/feedback` — list feedback
- `GET /api/feedback/:feedbackId` — view one feedback entry
- `POST /api/feedback` — create feedback
- `PUT /api/feedback/:feedbackId` — update feedback
- `DELETE /api/feedback/:feedbackId` — delete feedback

Course IDs are generated by the backend. Course duration is currently assigned a simple default of `8 weeks`, since duration is not a field in the requested form.
